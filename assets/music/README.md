# Main menu music

Place `main-menu-theme.ogg` in this folder. The game attempts to play it automatically when the main menu loads. Browsers that block audible autoplay start music on the first keyboard, pointer, or gamepad menu interaction.

**Expected asset path:** `assets/music/main-menu-theme.ogg`

If no hosted file exists, use **Options → Import theme (OGG/MP3) → Choose file** to select a local track instead. The player stores the chosen audio in browser storage for future visits when available. This does not upload audio to GitHub or share it with other players.

The menu music loops and fades in/out as you switch between menu, character select, and battles. Options has a separate music toggle and existing menu sound effects remain independent.

The uploaded OGG file is now bundled and used as the default music without a manual import. The game attempts to play on initial load; browsers that reject audible autoplay show a **Play Menu Music** prompt. Old iOS Safari may need `main-menu-theme.mp3`, which can be generated by `.github/workflows/menu-music-mp3.yml` when GitHub Actions is enabled. Verify the MP3 exists before relying on it.
